怎么创建 Token
  1. 打开 GitHub → Fine-grained tokens，新建一个。
  2. Repository access 选 Only select repositories，勾选 ogf-brand-index。
  3. Repository permissions 里把 Contents 设为 Read and write，其余不用给。
  4. 有效期按需设置，生成后复制 github_pat_… 粘贴到上面。

Token 只保存在浏览器本地，只用于调用 GitHub API 提交文件，不会写进仓库，也不经过任何第三方服务器。
